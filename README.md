# TODO List

A simple yet comprehensive task management web application designed for organizing daily tasks efficiently. This full-stack application provides users with a clean and straightforward solution for managing their to-do items with modern web technologies.

## Project Status

✅ **Project Almost Complete** - Most core features have been implemented and the application is nearly fully functional.

## Features

* **User Authentication** - Complete login and signup functionality
* **Simple Task Management** - Full CRUD operations (Create, Read, Update, Delete) for tasks
* **User Dashboard** - Clean and simple task overview and management
* **Theme Customization** - Light and dark mode toggle
* **Image Storage** - Cloudinary integration for profile pictures and attachments
* **Responsive Design** - Optimized for desktop, tablet, and mobile devices
* **Modern UI** - Clean and intuitive interface with Tailwind CSS and shadcn/ui components

## Technologies Used

### Frontend
* React.js - Component-based user interface
* Tailwind CSS - Utility-first CSS framework
* shadcn/ui - Modern UI component library
* React Router - Client-side routing

### Backend
* PHP - Server-side logic and API endpoints
* MySQL - Database management system

### Additional Services
* Cloudinary - Cloud-based image storage and management

## Architecture

This project follows a simple decoupled architecture with a React frontend communicating with a PHP backend through RESTful API endpoints, providing a clean and maintainable codebase.

## Installation & Setup (Local Development)

1. Clone the repository
2. Set up the PHP backend with your local web server (XAMPP, WAMP, etc.)
3. Configure MySQL database with the provided schema
4. Install frontend dependencies: `npm install`
5. Configure Cloudinary API keys in your environment
6. Start the development server: `npm start`

**Note:** This project is configured for local development environment.
